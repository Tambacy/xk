# 学校选课助手 v0.3.9

自动盯课余量、按预定时间抢课。全程用真实 Chromium 浏览器操作，不发送脚本化的后台请求。

> ⚠️ 仅供本人选课使用。请遵守学校相关规定，合理设置监听间隔。

## 相比 v0.3.8

### 修复

- 运行监控页的「已运行」一直停在 00:00:00，根本不走。调度器在一轮运行里
  **第一件事**就是推一个 `state=idle`（浏览器刚起来、还没进入监听），
  而界面把「不在运行中的状态」一律当作「已停下」，停表时连计时起点也清掉了 ——
  等真正进入「监听中」，表虽然在走、起点却已经没了

  > 这是 v0.3.1 修「停止后还在累加」时引入的，从 v0.3.1 到 v0.3.8 都在

### 改进

- 界面回归新增「已运行走字」检查，按调度器**真实的推送顺序**驱动
  （idle → preparing → monitoring）。只推 monitoring 是测不出这个 bug 的
