# 学校选课助手 v0.2.0

自动盯课余量、按预定时间抢课。**全程用真实 Chromium 浏览器操作** ——
登录、点页签、勾选课程、点提交都是像人一样的真实鼠标键盘事件，
不发送任何脚本化的后台请求。

> ⚠️ 仅供本人选课使用。请遵守学校相关规定，合理设置监听间隔，不要给服务器造成压力。

## 这一版修了什么

上一版有几个只在**真实环境**才暴露的问题，这一版全部在对真实教务系统实操的
过程中发现并修复。下面按"你会感受到的"顺序列。

### 1. 二次验证现在能真正走完了（上一版根本走不完）

学校的二次验证其实是**三步**，上一版只做了一半：

| 步骤 | 上一版 | 这一版 |
|---|---|---|
| ① 选择验证码发到哪（手机短信 / 企业微信） | ❌ 完全没处理 → 学校根本不会发验证码，于是"一直收不到验证码" | ✅ 弹出按钮让你选，程序替你点「确定」 |
| ② 输入 6 位验证码 | ⚠️ 输入框选择器靠猜 | ✅ 按真实页面（`#vericode`，6 位、**3 分钟**有效）实现；逐字真实键盘输入，填完回读确认 |
| ③ 「是否把本设备登记为信任设备」 | ❌ 完全没处理 → **学校不会自动跳转，登录永远完不成** | ✅ 单独问你，选「是」则 180 天内免验证码 |

> 「信任此浏览器」（登录页勾选框）和「登记信任设备」（第 ③ 步）是**两件不同的事**：
> 前者是学校的统一登录开关（免输账号密码），后者才免**验证码**。

另外修掉：
- **验证码误报**：真实登录页**永远**带着一段隐藏的验证码区块，上一版用"HTML 里
  有没有『验证码』字样"判断，条件恒为真 → 凭空要你输一个既不显示也没发送的码
- **等待中无法退出**：等你输验证码时关程序会卡住
- 程序里少了一个 `import random`，导致逐字输入验证码必然抛异常（上一版遇到
  二次验证**永远登不进去**）

### 2. 非体育课终于能监控到了

实测发现：必修 / 限选 / 任选的页面**不认 URL 参数**，而页面上那个「查询」
按钮的 `onclick` 在有的页面上**根本没定义**（点了毫无反应）。但**默认列表里
本来就有**目标课。改成「先读默认列表，找不到再按课程号搜、再按课程名搜」后，
8 门课里可监控的从 3 门变成 7 门。

### 3. 抢课决策的安全护栏（这条最重要）

加了「拿回来的必须就是目标课程号」的守门。**课序号都是 0/1/2 这种小数字**，
一旦页面返回的是别的课，很容易撞上一个相同的课序号 —— 那就会拿着**别人的
课**的 cid 去退课和提交，真的改掉学生的选课结果。宁可这一轮什么都不做。

配套修的：
- 回滚时**必须带上被退课程的课程号**（不带的话体育课页打开的是"全部体育课"
  列表 18 页，目标课根本不在上面 → 真出事时回滚会失效，等于白退一门课）
- 导航返回 ≠ 表格画好（JS 渲染），以前会误报「页面上找不到课程」而放弃，
  抢课时就白白错过一次机会
- 服务端的**硬拒绝**（「只能选一门」「不存在」「没有余量」等）不再白重试 3 次

### 4. 全程只有一个窗口

- 验证码在**程序主窗口**里输：图形验证码的图片直接截图显示在里面
- 浏览器窗口**随时可以关掉**，程序会自动在后台重开（同一份浏览器配置，
  登录态和信任状态都保留），不会中断，也不会弹回来打扰你
- 需要你本人操作时才弹出输入框；「取消登录」随时可用，关程序不再卡住

### 5. 模式二可以直接挑「要退的课」了

课程页新增「**本学期已选课程**」列表：从教务系统读回来直接显示，
每门课右边一个「要退」—— 点一下就加进要退清单。
**不用再去选课系统里翻课程号了。**

### 6. 凭据保护

- 明文 `secrets.json` 已迁移进 Windows DPAPI 加密存储，并从磁盘抹除
- 探针与测试统一走 `_creds.py`（环境变量 → DPAPI → 旧明文），不再各自硬编码读明文
- 明文 Cookie 文件已删除

### 7. 构建脚本

- `build.ps1` 补上 UTF-8 BOM（之前用文档里的 `powershell -File build.ps1` 会因为中文
  注释乱码而**直接解析失败**）
- 「自检不通过就中止」以前**是空的**：`XkHelper.exe` 是 GUI 子系统程序，
  `& exe` 之后 PowerShell 不等它，`$LASTEXITCODE` 残留在 0 → 自检失败也会照样发包。
  改用管道强制等待后读真实退出码
- 重建时先用 `rmdir` 摘掉目录联接，否则 PowerShell 5.1 的 `Remove-Item -Recurse`
  会顺着联接**删掉你本机 ms-playwright 里的真实浏览器**

### 8. 学号显示统一打码

启动时右上角显示的是**完整学号**，登录后才变成 `202****06` —— 两处格式不一致。
现在统一成打码格式，**截图、录屏、直播时不会整串学号露出来**。

> 顺带说明：安装包里**不含任何学号**。右上角那个学号来自你自己电脑上
> `%LOCALAPPDATA%\XkHelper\config.json`（登录时写入），随机器走、不随安装包走。
> 别人装完打开是空的。

## 安装使用

1. 双击安装包，一路下一步（不需要管理员权限）
2. 打开程序 → 输学号和密码 → 登录
3. 选运行模式
4. 填课程信息 → 「添加到清单」，程序会**自动去教务系统查证**
5. 「下一步」→「开始运行」→ **然后别关程序**

### 首次登录可能要求二次验证

程序会在这个窗口里问你三步（见上面第 1 条）。建议在第 ③ 步选「是」，
这样这台电脑 180 天内都不用再验证码 —— 半夜会话过期自动重登也不会被拦。
