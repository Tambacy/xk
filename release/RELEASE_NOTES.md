# 选课助手 v0.4.0

自动盯课余量、按预定时间抢课。全程用真实 Chromium 浏览器操作，不发送脚本化的后台请求。

> 本工具针对**某一所高校**的选课系统编写，仅在该系统上验证过。
> 个人学习项目，**不代表任何机构**。使用前请确认所在学校的规定。

## 相比 v0.3.0

### 变更

- 程序与安装包更名为 `XkHelper` —— 安装后的可执行文件、开始菜单和桌面
  快捷方式都同步用新名字
- 程序数据目录同步更名。升级时**会自动迁移**，账号密码与浏览器里的
  「信任此设备」状态都不受影响；万一迁移不成功会继续沿用旧目录，不会丢数据
- 升级安装会自动清理上一版的可执行文件，不留孤儿
- 界面左上角的圆形标志改为与应用图标一致的「选」

### 修复

- 无。功能与 v0.3.0 完全一致
