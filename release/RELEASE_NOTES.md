# 学校选课助手 v0.1.0

自动盯课余量、按预定时间抢课。**全程用真实 Chromium 浏览器操作** ——
登录、点页签、勾选课程、点提交都是像人一样的真实鼠标键盘事件，
不发送任何脚本化的后台请求。

> ⚠️ 仅供本人选课使用。请遵守学校相关规定，合理设置监听间隔，不要给服务器造成压力。

## 三种运行模式

按你当前处在选课的哪个阶段选：

| 模式 | 适用场景 | 它会做什么 |
|---|---|---|
| **一** | 选课还没开始（现在投了也要等抽签） | 填学校通知里的开始时间。程序提前开始盯「当前选课阶段」，一变成正选/补退选（先到先得）就自动选课 |
| **二** | 选课马上开始，且手上有课要让位 | 填开始时间 + 要退的课。到点先退课再抢；抢不到会自动把退掉的课选回来 |
| **三** | 选课进行中，目标课没余量，想蹲别人退课 | 长期后台监听，可设平均间隔（最长 1 小时）。发现余量立刻抢 |

三种模式的"拟人化"程度不一样，这是故意的：
模式一/三慢节奏（间隔随机长尾、偶尔拉长、夜间静默），
模式二等待期间拟人化、**动手那一瞬间全速**。

## 快速上手

1. 双击安装包，一路下一步（不需要管理员权限）
2. 打开程序 → 输学号和密码 → 勾上「信任此浏览器」→ 登录
3. 选运行模式
4. 填课程信息 → 点「添加到清单」，程序会**自动去教务系统查证**
5. 点「下一步」→「开始运行」→ **然后别关程序**

课程信息不用填全，能唯一定位到一门课就行。填不齐时程序会明确告诉你还缺什么。

---

## ⚠️ 首次登录可能要求二次验证

学校统一身份认证对**没见过的设备**会要求短信/微信验证码。

- 程序会自动识别这种情况，提示你**在弹出的浏览器窗口里完成验证**
- 完成一次之后，这台电脑就被记住了，以后登录不再需要
- **所以第一次登录请用默认的「可见窗口」模式**，不要改成后台无窗口

登录通常 10~40 秒（服务器繁忙时会到 1 分钟），界面会实时显示当前阶段和已用时间。

## 关于隐私

| 项目 | 怎么保护的 |
|---|---|
| 账号密码 | Windows DPAPI 加密存储，绑定当前用户 + 当前电脑，**明文不落盘** |
| 日志 | 密码、学号、Cookie 全部自动打码成 `***` |
| 诊断包 | 导出时自动脱敏，不含账号密码，可放心发给别人 |
| 安装包 | **不含任何账号数据**；凭据存在 `%LOCALAPPDATA%\XkHelper\`，不随安装分发 |

登录页底部有「清除本机已保存的账号密码」按钮，会连同浏览器登录态一起清掉。

## 出问题了怎么办

1. **先看日志** —— 监控页「打开日志」，或 `%LOCALAPPDATA%\XkHelper\logs\`
2. **跑自检** —— 在安装目录执行 `XkHelper.exe --selftest`，
   它会检查浏览器能否启动、能否连上学校网络，结论直接写在屏幕上
3. **导出诊断包** —— 监控页「导出诊断包」，打包日志 + 环境信息（已脱敏）

详细说明见安装目录下的 `使用说明.html`。

## 本版已知限制

- **中签率不受影响** —— 报名/抽签阶段由系统按教学计划和志愿等级决定，程序改变不了。
  它只在**先到先得**的阶段（正选、补退选）有用
- **必须让程序一直开着**，关了就等于停止抢课
- **电脑不能睡眠**（合盖/休眠会让监听暂停），建议接电源
- 首次登录如需二次验证，必须由真人完成，程序代替不了
- 仅支持本科生的选课系统

## 技术要点

- 用 Playwright 驱动**自带的完整 Chromium**，不是系统 Edge
  （实测系统 Edge 会被判为新设备从而要求二次验证）
- 会话过期自动重登；抢课中途掉线先重登再继续，不半途而废
- 轮询间隔随机浮动且**取值区间连续**（用乘法而非加法制造长尾停顿，
  否则直方图会留下永远取不到的空档，长期统计一眼就能看出是程序）
- 夜间 01:00~06:00 零请求

源码里 `README.md` 记了 11 条踩坑记录，包括登录过期是 200 而不是 401、
各类课程页列数不同必须按表头名映射、token 跨行导致单行正则全废等等。
