# 选课助手 v0.4.0

自动盯课余量、按预定时间抢课。全程用真实 Chromium 浏览器操作，不发送脚本化的后台请求。

> 本工具针对**某一所高校**的选课系统编写，仅在该系统上验证过。
> 个人学习项目，**不代表任何机构**。使用前请确认所在学校的规定。

## 相比 v0.3.0

### 变更

- **去掉了所有校名标识**。产品名、程序名、安装包名、仓库内容都不再出现具体
  学校名称 —— 原先只要搜那几个字就能搜到这个仓库
  - 程序名 `XkHelper.exe` → `XkHelper.exe`
  - 安装包 `XkHelper-Setup-*` → `XkHelper-Setup-*`
  - 显示名去掉校名，改为「选课助手」
  - 界面、说明、README、免责声明、许可协议里的相关字样一并改掉

- **数据目录改名并自动迁移**。程序数据目录从 `XkHelper` 改为 `XkHelper`。
  升级时会把旧目录**整个搬过去**（里面是加密凭据和浏览器 profile，
  「信任此设备」的状态就在里面）—— 搬不动就继续用旧的，绝不因为改名丢数据

### 请注意

- 程序**仍然会访问真实系统**：选课系统的域名写在代码里，删掉就不能工作。
  所以这是「不再被那几个字搜到」，**不是「匿名」** —— 读过源码的人依然能看出来
- 环境变量名 `XK_HOME` / `XK_USER` / `XK_PASS` 保持不变（开发与测试用，
  改了会让已有的本机脚本失效）

### 修复

- 无。这一版只做改名，功能与 v0.3.0 完全一致
