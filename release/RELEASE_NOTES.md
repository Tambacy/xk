# 学校选课助手 v0.2.0

自动盯课余量、按预定时间抢课。全程用真实 Chromium 浏览器操作，不发送脚本化的后台请求。

> ⚠️ 仅供本人选课使用。请遵守学校相关规定，合理设置监听间隔。

## 下载

| 文件 | 说明 |
|---|---|
| `XkHelper-Setup-0.2.0.exe` | 安装包，推荐。自包含（内置一整个 Chromium），装完即用 |
| `XkHelper-v0.2.0-source.zip` | 源码，想自己改或自己构建就下这个 |

## 相比 v0.1.0

### 修复

- **二次验证流程补全**。此前只做到输入验证码，缺「选择验证方式」和「登记信任设备」两步，导致验证码发不出来、登录无法完成
- 修正验证码区块的误判，不再在未发送验证码时要求输入
- 修正逐字输入验证码时的异常

### 改进

- 二次验证在主窗口内完成，不再有独立弹窗
- 浏览器窗口关闭后自动在后台重开，登录状态保留
- 必修 / 限选 / 任选课程现在能读到列表并监控（可监控课程由 3 门增至 7 门）
- 课程页新增「本学期已选课程」，可直接勾选要退的课，不必再自己查课程号

### 安全

- 提交前校验课程号，避免课序号相同而操作到其他课程
- 回滚退课时携带课程号
- 账号密码改用 Windows DPAPI 加密存储，明文文件已从磁盘清除
- 界面中的学号做打码显示

### 构建

- 修正构建脚本「自检失败仍会出包」的问题
- 修正重建时可能误删本机 Playwright 浏览器的问题

## 安装使用

1. 双击安装包，一路下一步（不需要管理员权限）
2. 输入学号和密码登录
3. 选择运行模式
4. 填写课程信息并添加到清单，程序会自动去教务系统查证
5. 下一步 → 开始运行

首次登录若被要求二次验证，按界面提示操作即可。建议在「是否登记信任设备」一步选「是」。
