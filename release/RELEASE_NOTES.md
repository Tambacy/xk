# 选课助手 v0.5.0

自动盯课余量、按预定时间抢课。全程用真实 Chromium 浏览器操作，不发送脚本化的后台请求。

> 本项目是个人学习项目，与任何高校及其院系没有任何关系，未获授权。
>
> **本项目仅供个人学习与技术研究，不得用于真实选课。**
>
> 使用自动化工具选课可能违反学校规定，可能导致选课结果被取消、账号受限。
> **全部风险由使用者自行承担，作者不承担任何责任。** 请合理设置监听间隔，
> 不要给服务器造成压力。
>
> 禁止商业用途、代抢服务与大规模分发。

## 相比 v0.4.0

本次更新集中在两件事：让浏览器行为更接近真人操作，以及修掉几处稳定性问题。

### 浏览器行为

- 浏览器版本号、平台、语言等标识与真实 Chrome 完全对齐。对齐发生在浏览器
  进程内部，页面脚本看到的仍是原生值
- 取消后台无窗口模式，统一使用可见窗口
- 中文课程名改为「复制粘贴」方式输入，产生完整按键事件，与真人操作一致；
  用后会还原你原本的剪贴板内容
- 轮询间隔的随机分布更接近真人节奏，不再存在固定的取值上限。平均速度不变
- 空闲时会偶尔浏览其他页面、调整窗口大小、开个标签页再切回来
- 夜间静默期间，上述行为一并停止

### 修复

- **修正登录判断**：以前只根据「落地页在教务域名下」就判定登录成功。在学校
  会话处于中间态时，会出现「提示登录成功、实际会话无效」，导致随后每次轮询
  都撞会话失效、反复重登。现在会真正读取一次数据页来确认
- 等待选课开始的阶段，夜间不再发出请求
- 启动自检不再以无窗口方式访问选课系统

### 使用提示

- 在新设备上首次使用，可能需要在弹出的浏览器窗口里手动完成一次二次验证；
  完成后这台设备会被记住，之后不再要求
- 无需额外设置，升级后直接使用
