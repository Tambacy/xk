# 选课助手 v0.4.3

自动盯课余量、按预定时间抢课。全程用真实 Chromium 浏览器操作，不发送脚本化的后台请求。

> 本项目是个人学习项目，与任何高校及其院系没有任何关系，未获授权。
>
> **本项目仅供个人学习与技术研究，不得用于真实选课。**
>
> 使用自动化工具选课可能违反学校规定，可能导致选课结果被取消、账号受限。
> **全部风险由使用者自行承担，作者不承担任何责任。** 请合理设置监听间隔，
> 不要给服务器造成压力。
>
> 禁止商业用途、代抢服务与大规模分发。
