# 选课助手 v0.4.0

自动盯课余量、按预定时间抢课。全程用真实 Chromium 浏览器操作，不发送脚本化的后台请求。

> 本项目是个人学习项目，与任何高校及其院系没有任何关系，未获授权。
>
> **本项目仅供个人学习与技术研究，不得用于真实选课。**
>
> 使用自动化工具选课可能违反学校规定，可能导致选课结果被取消、账号受限。
> **全部风险由使用者自行承担，作者不承担任何责任。** 请合理设置监听间隔，
> 不要给服务器造成压力。
>
> 禁止商业用途、代抢服务与大规模分发。

## 相比 v0.3.0

### 变更

- 程序与安装包更名为 `XkHelper`。安装后的可执行文件、开始菜单和桌面快捷方式
  都同步用新名字，升级安装会自动清理上一版的文件
- 程序数据目录同步更名。升级时**会自动迁移**，账号密码与浏览器里的
  「信任此设备」状态都不受影响；万一迁移不成功会继续沿用旧目录，不会丢数据
- 界面左上角的圆形标志改为与应用图标一致的「选」
- 使用说明里的使用范围说明写得更清楚

### 修复

- 无。功能与 v0.3.0 一致
