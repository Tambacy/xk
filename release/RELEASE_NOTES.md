# 学校选课助手 v0.3.0

自动盯课余量、按预定时间抢课。全程用真实 Chromium 浏览器操作，不发送脚本化的后台请求。

> ⚠️ 仅供本人选课使用。请遵守学校相关规定，合理设置监听间隔。

## 下载

| 文件 | 说明 |
|---|---|
| `XkHelper-Setup-0.3.0.exe` | 安装包，推荐。自包含（内置一整个 Chromium），装完即用 |
| `XkHelper-v0.3.0-source.zip` | 源码，想自己改或自己构建就下这个 |

## 相比 v0.2.0

### 改进

- **界面整体改版**。主色由紫色改为淡紫，五个页面统一了配色、字号层级与间距
- 窗口顶部与登录页新增**夜空天幕**：极光、星点与同心弧纹，随窗口缓慢漂移；
  五个页面各用一种天幕「心情」，切页时背景随之变化
- 登录页由居中单卡片改为「品牌区 + 表单」分栏
- 步骤进度由互不相连的标签改为带连接线的步骤导轨
- **页面切换改为粒子渐变揭示**：新页从中心化开，边缘跑一圈粒子
- **按钮增加粒子**：悬停与点击时沿按钮边缘溅出，并受重力回落
- 统计数字滚动、运行中状态点呼吸
- 课程卡片增加左侧状态色条，校验状态可直接看出
- 顶部天幕带高度由 176px 压到 142px，操作区域不再被顶到下面
- 滚动条改为悬停显形，平时完全透明
- `docs/使用说明.html` 改为**翻页式演示稿**：一页一屏、19 屏，
  每屏独立背景（CSS/SVG 现画，无外链图片），全局粒子层，逐条浮起的入场动画

### 修复

- **运行监控页此前没有任何返回入口**：点完「停止」就卡在该页，只能关掉程序重开。
  现停止或跑完后显示「返回设置」，可直接回到设置页改完重跑
- 页面切换时出现大片黑色：切页快照只取了内容区、没取顶部区域，
  且透明控件未铺底，未绘制处露出未初始化内容
- 页面切换掉帧：改为自绘计时器驱动并只重画变化区域
- 运行监控页在窗口高度不足时内容被截断，现改为可滚动
- 模式选择页与确认页同样补上滚动区
- 学号打码此前只在顶部导航显示；登录页不显示导航，看不到打码结果。现两处一致

### 构建

- 应用图标改用与界面一致的主色，并补充窗口图标设置
- `XkHelper.exe` 补齐产品名与版本号（此前属性页为空白）

### 未包含

- 选课、登录、调度逻辑无改动
- 未引入任何新的第三方依赖（动效与背景均使用 Qt 自带能力与 CSS/SVG）

## 安装使用

1. 双击安装包，一路下一步（不需要管理员权限）
2. 输入学号和密码登录
3. 选择运行模式
4. 填写课程信息并添加到清单，程序会自动去教务系统查证
5. 下一步 → 开始运行

首次登录若被要求二次验证，按界面提示操作即可。建议在「是否登记信任设备」一步选「是」。
